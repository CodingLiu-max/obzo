# OBZO

OBZO（Obsidian + Zotero）用于构建以证据为基础的科研学习与工程知识库。

它可以在限定范围内检索和筛选权威论文，设计学习或工程路线，整理 Obsidian 笔记，并将论文元数据与合法 PDF 镜像到 Zotero。

## 文件

- `SKILL.md`：Skill 入口和核心规则
- `WORKFLOW.md`：检索、筛选、阅读、整理和同步流程
- `TEMPLATES.md`：学习路线、工程路线和论文笔记模板
- `USAGE.md`：可复制的调用提示词

## 调用

在 Codex 中显式说明：

```text
使用 OBZO 扩充我的学习体系。
```

同时提供主题、Obsidian 目录、路线范围、论文数量上限、时间范围以及 Zotero 操作范围。OBZO 默认控制检索规模，优先保证关键权威路线完整，不把知识库变成论文堆。
